🔎 when / if / because ── 2つの文をつなぐことば

when ＋ 文
「〜するとき・〜したとき」
When the typhoon left, we flew to Hong Kong.（台風が去ったとき）
if ＋ 文
「もし〜なら」
If he drinks a lot of water, he will feel better.（もし水をたくさん飲めば）
because ＋ 文
「〜なので・〜だから」（理由）
I need some medicine because my grandpa has a fever.（熱があるので）

when や if のあとは、これからのことでも現在形を使うよ。If he will drink ではなく If he drinks。
